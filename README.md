# 🖤 Nextfit — Modern MERN Clothing E-Commerce Platform

**Nextfit** is a modern **dark-themed full-stack e-commerce web application** built using the **MERN Stack (MongoDB, Express, React, Node.js)**.

The platform is designed for selling **Men's Fashion Products including Suits and T-Shirts**, providing a smooth shopping experience for customers and a powerful **Admin Dashboard** for store management.

This project focuses on **real-world workflow, clean UI/UX, scalable architecture, and modern design**.

# ✨ Key Features

## 🛍️ Customer Side

* Modern responsive **online clothing storefront**
* Product listing with **multiple images**
* **Size-based product selection**
* Add to cart functionality
* Cart management system
* **Cash on Delivery (COD)** checkout
* **Karachi free delivery logic**
* Simple and fast **order placement**
* Mobile-first responsive design
* **Dark futuristic UI**

---

## ⚙️ Admin Dashboard

* Secure **Admin Panel**
* Add new products
* Update product details
* Delete products
* Upload **multiple product images**

* Update order status
* Manage store inventory easily

# ⚙️ Installation Guide

### 1️⃣ Clone Repository

```
git clone https://github.com/yourusername/Nextfit.git
```

```
cd Nextfit
```

---

### 2️⃣ Install Client

```
cd client
npm install
npm run dev
```

Client will run on:

```
http://localhost:5173
```

---

### 3️⃣ Install Admin Dashboard

```
cd admin
npm install
npm run dev
```

Admin will run on:

```
http://localhost:5174
```

---

### 4️⃣ Run Server

```
cd server
npm install
node server.js
```

Server will run on:

```
http://localhost:5000
```

---

# 📦 Environment Variables

Create a `.env` file inside the **server folder** and add:

```
MONGO_URI=your_mongodb_connection
CLOUDINARY_NAME=your_cloudinary_name
CLOUDINARY_KEY=your_cloudinary_api_key
CLOUDINARY_SECRET=your_cloudinary_secret
PORT=5000
```
