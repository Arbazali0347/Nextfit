# 🖤 Nextfit — Modern MERN E-Commerce Platform

Nextfit is a modern, dark-themed full-stack e-commerce web application built using the MERN stack.  
It provides a smooth shopping experience for customers and a powerful admin dashboard for store management.

> Built with focus on real-world workflow, clean UI/UX, and scalable architecture.

---

## 🚀 Live Demo

- 🌐 Frontend: [https://nextfit-seven.vercel.app/]
---

## ✨ Key Features

### 🛍️ Customer Side

- Modern responsive storefront  
- Product listing with multiple images  
- Size-based pricing system  
- Add to cart functionality  
- Cart management  
- Cash on Delivery (COD) checkout  
- Karachi free delivery logic  
- Order placement system  
- Mobile-first responsive design  
- Dark futuristic UI  

---

### ⚙️ Admin Dashboard

- Secure admin panel  
- Add new products  
- Update products  
- Delete products  
- Upload multiple product images  
- View all orders  
- Update order status  
- Easy inventory management  

---

## 🧠 Tech Stack

### Frontend
- React.js  
- Tailwind CSS  
- React Router  
- Context API  

### Backend
- Node.js  
- Express.js  
- MongoDB  
- Mongoose  
- Multer (image upload)  
- Cloudinary (image hosting)
